## Thread and Concurrency Model

```
┌─────────────────────────────────────────────────────────────┐
│                    THREADING MODEL                          │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                 MAIN UI THREAD                      │   │
│  │                                                     │   │
│  │  ┌─────────────┐    ┌─────────────┐                │   │
│  │  │    Input    │ →  │   Event     │                │   │
│  │  │  Handler    │    │ Processing  │                │   │
│  │  │             │    │             │                │   │
│  │  └─────────────┘    └──────┬──────┘                │   │
│  │                            │                       │   │
│  │                            ▼                       │   │
│  │  ┌─────────────┐    ┌─────────────┐                │   │
│  │  │  Business   │ →  │     UI      │                │   │
│  │  │    Logic    │    │   Update    │                │   │
│  │  │  Execution  │    │             │                │   │
│  │  │             │    │             │                │   │
│  │  └─────────────┘    └─────────────┘                │   │
│  │                                                     │   │
│  │  All operations execute synchronously               │   │
│  │  on the main thread (appropriate for               │   │
│  │  lightweight operations like dice rolling)         │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              NO BACKGROUND THREADS                  │   │
│  │                                                     │   │
│  │  - No network operations                            │   │
│  │  - No database operations                           │   │
│  │  - No file I/O operations                           │   │
│  │  - No long-running computations                     │   │
│  │                                                     │   │
│  │  Simple synchronous execution model                 │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```
