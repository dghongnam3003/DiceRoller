# Dice Roller App

## Overview
This is a simple Android application that simulates rolling a dice. Users can tap a button to roll a virtual dice and see the result displayed on the screen.

## Features
- Roll a 6-sided dice
- Display the result of the dice roll
- Simple and intuitive user interface

## Installation
To install and run this app:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/dice-roller.git
   ```

2. Open the project in Android Studio.

3. Build and run the app on an Android emulator or physical device.

## Usage
1. Open the app on your Android device.
2. Tap the "Roll" button to roll the dice.
3. The result will be displayed on the screen.

## Code Structure
- `MainActivity.kt`: Contains the main logic for the app, including the dice rolling functionality.
- `activity_main.xml`: Defines the user interface layout.
- `Dice` class: Handles the dice rolling logic.

## Dependencies
- AndroidX libraries
- Kotlin standard library
