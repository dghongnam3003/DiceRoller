# Dice Roller App

## Overview
This is a simple Android application that simulates rolling a dice. The app allows users to roll a virtual dice and view the result.

## Features
- Roll a dice with a single tap
- View the result of the dice roll
- Simple and intuitive user interface

## Installation
To install and run the app:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/dice-roller.git
   ```

2. Open the project in Android Studio.

3. Build and run the app on an Android device or emulator.

## Usage
1. Open the app on your Android device.
2. Tap the "Roll" button to roll the dice.
3. The result will be displayed on the screen.

## Technical Details
- **Language**: Kotlin
- **Platform**: Android
- **Minimum SDK**: 21
- **Target SDK**: 34
